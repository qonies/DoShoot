## 1. 项目概述

### 1.1 背景与目标
- 同类浏览器 .io 射击游戏验证了"浏览器 + 免注册 + 快节奏多人射击"的产品模型，具备低成本获客、高留存的特点。本项目为同类玩法的原创实现，不使用任何第三方游戏资源或代码。
- 本项目目标是复刻其核心体验：**打开网页 → 输入昵称 → 10 秒内进入对局 → 快节奏射击对抗**。
- 作为自研项目，重点在于完整实现：伪 3D 俯视角渲染、低延迟实时联网、武器成长系统。

### 1.2 范围
- **V1（MVP+）**：单人可玩的完整战斗核心 + 联机 FFA（自由对战）+ 2~3 张地图 + 6 类武器 + 武器击杀解锁进度。
- **V2**：TDM、Hardpoint 模式，账号与战绩系统，反作弊加固，更多地图与武器。
- 明确不做：移动端触控适配（V1）、语音聊天、充值/商业化。

### 1.3 目标用户
- 能访问现代浏览器（Chrome/Edge/Firefox/Safari 最新两个大版本）的 PC 玩家。
- 期望单局 3~5 分钟、零学习成本的休闲竞技玩家。

## 2. 对标玩法拆解（同类 .io 俯视角射击游戏）

| 维度 | 同类产品的常见做法 | 本项目取舍 |
|---|---|---|
| 视角 | WebGL 伪 3D 俯视角，角色有立体模型/光影/枪口火焰 | 完全复刻（Three.js） |
| 进入方式 | 免注册，输入昵称即玩 | V1 完全一致 |
| 操作 | WASD 移动、鼠标瞄准/射击、R 换弹、数字键切枪 | 完全一致 |
| 模式 | FFA、TDM、Hardpoint、One in the Chamber、Gun Game | V1 先 FFA，V2 扩展 |
| 武器成长 | 每把武器按击杀数逐级解锁更强武器/配件 | 完全一致（简化配件） |
| 地图 | 掩体+箱子+墙体的小型对称地图，节奏快 | 一致，2~3 张 |
| 联网 | 权威服务端、房间制、低延迟同步 | 一致 |

## 3. 玩家流程（用户故事）

1. 作为玩家，我打开网页后看到一个大厅页，输入昵称即可点击"开始游戏"，无需注册。
2. 作为玩家，我可以在大厅选择游戏模式和地图（或"快速加入"由系统分配）。
3. 作为玩家，进入对局后我用 WASD 移动、鼠标瞄准、左键射击、R 换弹、1~3/滚轮切枪。
4. 作为玩家，我被击杀后 2~3 秒内在安全出生点复活，不退出对局。
5. 作为玩家，我用某把武器击杀越多，就越快解锁该武器线的下一把武器。
6. 作为玩家，我随时按 Tab 看实时计分板，Esc 打开设置（音量、画质、灵敏度）。
7. 作为玩家，对局结束（达到时限/分数）后看到结算排名，一键"再来一局"。

## 4. 功能需求（FR）

### 4.1 大厅与进入（Lobby）
- FR-L1 免注册进入：昵称（默认随机，可改，2~16 字符，非法字符过滤），本地记忆上次昵称。
- FR-L2 模式选择：FFA（V1）；预留 TDM / Hardpoint 入口（V2 解锁，置灰展示）。
- FR-L3 地图选择：下拉或卡片选择地图 + "随机"。
- FR-L4 快速加入：按当前房间人数自动分配到人最多的非满房间；无可用房间则新建。
- FR-L5 设置持久化（M4 已实现，Esc 面板）：音量、BGM 音量、画质等级、界面语言存 localStorage；鼠标灵敏度项因 V1 绝对指针瞄准（无指针锁定）不适用。
- FR-L6 多语言：支持中文 / English 切换（大厅可手动切换，默认跟随浏览器语言），所有 UI 文案走 i18n 资源文件，禁止硬编码。

### 4.2 战斗核心（Combat）
- FR-C1 移动：WASD 八方向移动，速度固定（无冲刺/跳跃，同类产品通行做法），碰撞掩体不可穿越。
- FR-C2 瞄准与射击：准星跟随鼠标（世界坐标）；按住左键连发；子弹为射线/短弹道判定。
- FR-C3 生命与伤害：HP 100（V1 不做护甲）；受击有屏幕泛红 + 伤害数字飘字；击杀奖励显示（击杀图标流）。
- FR-C4 死亡与重生：死亡镜头停留 1.5s 显示击杀者信息，2~3s 后在距敌人最远的出生点复活，满状态。（**实现现状**：死亡立即显示全屏遮罩+击杀者+倒计时，无 1.5s 镜头停留；重生延迟 2.5s）
- FR-C5 掩体：墙体/箱子阻挡移动与子弹；箱子高度低于视线挡子弹（俯视角规则简化为：全部阻挡，V1 不做高度差）。
- FR-C6 状态同步表现：其他玩家移动/开枪/换弹/死亡均有动画与音效反馈。

### 4.3 武器系统（Weapons）
| 槽位 | 类别 | 参考数值（伤害/射速/弹匣/换弹） | 定位 |
|---|---|---|---|
| 1 | 手枪 Pistol | 25 / 半自动 / 12 / 1.2s | 初始武器 |
| 2 | 冲锋枪 SMG | 15 / 900rpm / 30 / 1.6s | 近战高机动 |
| 3 | 突击步枪 AR | 25 / 600rpm / 30 / 1.8s | 全能主力 |
| 4 | 霰弹枪 Shotgun | 8×8 颗 / 泵动 / 6 / 2.2s | 近距离爆发 |
| 5 | 狙击枪 Sniper | 110 / 栓动 / 5 / 2.5s | 远程一击 |
| 6 | 轻机枪 LMG | 22 / 700rpm / 75 / 3.5s | 压制火力 |

- FR-W1 每类武器一条解锁链：按该类累计击杀数升级（如 Pistol→双持→左轮），解锁即时生效并全屏提示。
- FR-W2 武器数值差异还包括：射程衰减、散布（移动时扩大）、后坐力（准星上跳/镜头震动）。
- FR-W3 换弹：R 键或弹尽自动换弹，进度条显示；切枪打断换弹。
- FR-W4 出生携带：**定稿（v0.3.0）**——携带全部 6 类武器，各类按其解锁链当前层级出战（M1/M2 简化方案延续为正式规则）；数字键 1~6 / 滚轮切换，出生满弹匣 + 满备弹；升级即时生效并奖励满新弹匣。
- FR-W5 所有武器数值集中在共享配置包，客户端服务端同源加载。禁止客户端作为伤害/击杀等权威结果的最终裁决方；客户端预测仅用于表现（见 FR-N4），最终以服务端裁决为准。

### 4.4 游戏模式（Modes）
- FR-M1 FFA：个人战，先达到 30 杀或时限（5 分钟）结束，按击杀数排名。
- FR-M2 TDM（V2）：8v8 上限，团队击杀总和先到 75 或时限结束。
- FR-M3 Hardpoint（V2）：据点周期刷新，占点得分，先到分数上限或时限结束。
- FR-M4 对局结束 → 结算面板（排名、K/D、武器统计）→ "再来一局"回大厅或直接重开。

### 4.5 地图系统（Maps）
- FR-MP1 地图用 JSON/Tile 数据描述：墙块、箱子、装饰、出生点、（V2）据点；尺寸约 40×40 格（每格 1 单位）。
- FR-MP2 V1 至少 2 张风格不同地图（开阔狙击型 / 狭巷近战型）。
- FR-MP3 出生点规则：优先远离所有敌人视线与距离的候选点。
- FR-MP4 地图数据由共享包加载，服务端用其做碰撞与射线检测，客户端用其做渲染。

### 4.6 UI / HUD
- FR-U1 HUD：血条、当前武器 + 弹匣/备弹、击杀信息流（右上）、计分板（Tab）、准星（动态扩散）。
- FR-U2 小地图（M4 已实现）：左上角，显示墙体轮廓 + 自己位置/朝向（V1 不显示敌人，同类产品惯例）。
- FR-U3 受击方向指示器 + 低血量屏幕边缘泛红。（**V1 现状：简化实现**——仅有受击泛红 vignette；方向指示器与低血量边缘泛红未实现，见 v0.3.1 修订说明）
- FR-U4 大厅 UI 与 HUD 用 DOM/HTML 实现，游戏内世界对象用 Three.js，两者分层。
- FR-U5 死亡/复活全屏遮罩、对局倒计时、结束结算面板。

### 4.7 音效
- FR-S1 基础音效：各武器开火、命中音、换弹、脚步、死亡、击杀提示、UI 音。（**V1 现状：子集**——射击/命中/受击/击杀/换弹/死亡/解锁/结算为 WebAudio 合成；脚步与 UI 音未实现）
- FR-S2 空间音频（M4 已实现，WebAudio StereoPanner）：远端枪声按声源方位声像 + 距离衰减。
- FR-S3 BGM（M4 简化实现）：WebAudio 合成环境音循环，音量独立控制；大厅/对局共用一首（区分场景曲目后置）。

### 4.8 账号与数据（V2，V1 仅本地）
- FR-A1 V1：武器解锁进度以 localStorage 本地记录为唯一持久层（**默认开启**，保证成长跨局可见，见决策 #9）；对局进行中的进度由服务端权威计数（见 FR-W5），服务端持久化留 V2。
- FR-A2 V2：可选游客账号（设备指纹/Token），跨局持久武器进度、战绩统计（K/D、胜率）。

### 4.9 Bot 假人（正式功能）
- FR-B1 自动填充：房间人数不足时自动补充 Bot（默认最多 5 个 Bot，对应 shared 常量 `BOT_FILL_MAX`，空房与真人不足时补齐），真人加入时优先顶替 Bot；真人离开不足时回填。
- FR-B2 Bot AI：简单状态机（巡逻 → 视线发现目标 → 追击/射击 → 低血量走位躲避），移动寻路基于地图数据做视线/网格寻路（A* 或可视线段法）。
- FR-B3 难度可配：瞄准误差、反应延迟、移动激进度三档难度；建房时可选择（默认中等）。
- FR-B4 公平管线：Bot 使用与真人完全相同的武器数值、移动上限与服务端模拟管线，无任何特权代码路径。
- FR-B5 成长计数：击杀 Bot 计入武器解锁进度（内部测试默认开启，留配置开关）。

### 4.10 彩蛋功能（Easter Egg）
- FR-E1 冲锋枪彩蛋模式（v0.3.2）：对局进行中，玩家依次输入特定 4 位数字口令 **`7890`**（shared `CHEAT_RUSH_CODE`，可改常量）并按 Enter，切换到「狂暴冲锋枪」（WeaponId `rush`，不入 WEAPON_ORDER 槽位）：
  - 数值：1200rpm 超高射速、16 伤害、满伤射程 40 / 最大射程 60（全图级）、低散布低后坐力、**无限弹药**（弹药不消耗、禁用换弹，HUD 显示 ∞）。
  - 生命周期：服务端口令验证后权威授予（C2S `rush` 消息，NFR-5 防伪造）；当局内**跨重生保留**；**回合结束（30 杀 / 时限 matchEnd）自动失效**，不带到下一局；断线 30s 内重连回原状态时保留（FR-N5）。
  - 约束：数字键 1~6 切枪热键不受影响（口令不含 1~6）；客户端切枪输入白名单不可获得/切走 rush；**彩蛋模式中手动切枪 = 主动放弃彩蛋**（rushActive 复位，可重新输入口令再次激活，避免无限弹药泄漏到常规武器）；rush 击杀不计入武器解锁进度（FR-W1/A1）与 localStorage 进度；Bot 不会获得。

## 5. 网络与同步需求（Networking）

- FR-N1 **权威服务端**：位置、射击、命中、伤害、死亡、复活全部由服务端模拟与裁决；客户端输入仅作为意图上报。
- FR-N2 **Tick 频率**：服务端 accumulator 固定步长模拟 30 tick/s；快照广播 20~30 次/s（V1 为每 tick 全量快照、JSON 编码；增量/定点数/字节布局编码后置至 M4 优化，见决策 #8）。V1 广播范围为整个房间（10 人全量），**不做兴趣区域过滤**（V2 视规模引入）。
- FR-N3 **插值**：远端玩家按 ~100ms 插值缓冲平滑渲染，容忍单次丢包不抖动。
- FR-N4 **本地预测**：自己角色的移动客户端即时预测 + 服务端权威位置和解（reconciliation，seq ack + 未确认输入重放）；射击命中带**延迟补偿回溯（M4 已实现）**——服务端保存 ~1s 实体位置历史，按「插值延迟 + 半程 RTT」回溯命中判定（Bot 回溯为 0）。
- FR-N5 **断线重连**：意外断线 30s 内重连可回到对局原状态；超时视为离开并踢出房间。
- FR-N6 **房间管理**：房间人数上限 10（FFA），空房间 60s 后回收；进房走统一匹配接口。
- FR-N7 **协议版本化**：消息带版本号，前后端不匹配时拒绝进入并提示刷新。

## 7. 技术路线（已确认）

| 层次 | 选型 | 说明 |
|---|---|---|
| 渲染 | **Three.js**（WebGL2，正交/小透视俯视角相机） | 用户已确认；角色用低模组合几何体 + 简单光照阴影 |
| 语言 | TypeScript（全栈） | 类型安全的共享协议与数值 |
| 构建 | Vite | 客户端构建；shared 以 TS 源码形式被两端引用 |
| 服务端 | Node.js + Socket.IO（已定稿） | 不使用 Colyseus；房间管理与匹配自研 |
| 多语言 | 自研轻量 i18n（JSON 资源 + 切换函数） | 中/英两套资源文件，默认跟随浏览器语言 |
| 碰撞 | 自研 AABB + 圆形碰撞 + 射线检测 | 场景规则简单，无需重型物理引擎 |
| UI | 原生 DOM + CSS（大厅/HUD） | 不引入 React，降低复杂度 |
| 资源 | 模型用 Three.js 基础几何体拼装；音效用免费素材 | V1 不依赖美术外包 |
| 部署 | **局域网直接 Node 运行**（内部测试用途） | 无需域名/HTTPS/备案/云服务器；开发机起服务后同一局域网设备输入 IP 即可加入；后续若公网上线再补 Docker/Nginx |
| 仓库 | pnpm monorepo：`apps/client` / `apps/server` / `packages/shared` | |

### 关键技术要点
1. **固定步长模拟**：服务端 accumulator 循环，30Hz 确定性模拟（不受 setInterval 定时器粒度影响）。
2. **快照**：V1 每 tick 全量快照（20~30Hz，JSON 编码，跨步事件捎带）；增量/二进制编码（定点数/字节布局）列为 M4 优化项（决策 #8）。
3. **延迟补偿（M4 已实现）**：服务端保存最近 ~1s 实体位置历史（每 tick 记录），命中判定回溯到射击者视角时刻（插值延迟 + 半程 RTT，上限 400ms；Bot 回溯为 0）。
4. **数值同源**：武器/地图配置放 `packages/shared`，杜绝两端不一致。
