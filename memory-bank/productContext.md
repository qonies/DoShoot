# 产品上下文（Product Context）

## 为什么做
- 复刻同类 .io 射击游戏验证过的产品模型：浏览器免注册 + 快节奏多人射击，低门槛高留存。
- 同时作为实时联网游戏完整技术栈（渲染、物理、同步、部署）的实践项目。

## 要解决的问题
- 传统端游/手游射击门槛高（下载、注册、配置）；.io 游戏即开即玩。
- 玩家需要 3~5 分钟一局的碎片化竞技体验。

## 期望的用户体验
1. 打开网页 → 输入昵称 → 选模式/地图 → 匹配进入，全程 < 15 秒
2. 操作直觉化：WASD + 鼠标，零教学成本
3. 对局节奏快：TTK 短、重生快（2~3 秒）、死亡立刻再战
4. 成长可见：每把武器的击杀进度条、解锁提示
5. 流畅：客户端渲染 ≥ 60 FPS，操作到画面响应 < 100ms（局域网 < 50ms）
