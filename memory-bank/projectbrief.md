# 项目简报（Project Brief）

## 项目名
DoShoot Web — 浏览器多人在线俯视角射击游戏（对标同类 .io 射击游戏，原创实现）

## 核心需求
1. 打开网页、输入昵称、10 秒内进入对局（免注册）
2. Three.js 伪 3D 俯视角渲染（用户已确认此技术路线）
3. 权威服务端 + WebSocket 实时多人同步（房间制）
4. 战斗核心：WASD 移动、鼠标瞄准射击、换弹/切枪、掩体碰撞、生命/重生
5. 武器系统：6 类武器，按击杀数逐级解锁（同类产品通行做法）
6. 游戏模式：V1 = FFA；V2 = TDM、Hardpoint
7. 地图：2~3 张掩体型小地图，单局 3~5 分钟

## 范围约束
- V1 不做：移动端触控、语音、商业化、账号系统（昵称即玩）
- 平台：现代桌面浏览器
- 部署：**局域网内部测试**，不做公网/备案/HTTPS
- 多语言：**中英文双语（i18n）**
- Bot 假人：**正式功能**（房间自动填充 + 简单 AI）
- 已确认决策：Socket.IO（不用 Colyseus）、几何体拼装 + 免费素材、每房 10 人
